# asis : 출시알림 신청 이메일 등록란 + 홍보용 간단한 기능 (주소 입력시 건출물 대장 기준 외도민 등록 가능성 판별, 사용자 선택하는 반경 거리 100M ~ 1KM 사이 경쟁숙소 * 외도민 기준 개수, 수익성 계산기)

# tobe : 실제운영용으로 웹 구조 변경

## 레퍼런스 사이트 : 나이스비즈맵, smoothAI

## 상단 메뉴
- 좌측상단 : 로고, 홈(누르면 홈으로 이동), 분석하기(누르면 실제 분석기능이 있는 /explore로 이동), 행사소식(에버이내비  호스트가 가격조정에 도움받을 수 있는 월별 행사소식 * 레퍼런스 사이트 : 스테이달력), 가격(요금제 소개)
- 우측상단 : 로그인 / 회원가입

## 주요기능들 소개
- 가장 중심부 즈음에 '무료로 분석하기' 버튼(누르면 실제 분석기능이 있는 /explore로 이동)
- 실제 어떻게 사용될 수 있는지 움짤 파일 등
- 사용해본 에어비앤비 실제 호스트 후기 (3*2로 6개 정도 후기 배치하기)
- 이 사이트를 통해서 일일이 분석해야 하던 문제점을 asis와 tobe로 비교하여 사이트가 매력적이게 느껴질수있게끔 하는 요소들 장식

## 요금제 소개

# 기본 사용자 여정
분석하기(/explore) 클릭 -> 지도에서 사용자가 관심갖는 위치(동네단위) 선택 -> 개수 알수있음(외도민 기준 총개수, 단위면적당 총 외도민 개수) : 이때 총개수는 미리 각 동네에 몇개인지 표출 + 외도민 등록된 업체 핀으로 확인가능
 -> 유료기능 확인 : 회원 전용 (카카오톡 로그인 or 구글 로그인 선택가능) * 즉 무료기능은 외도민 기준 업체만 확인가능

# 유료 기능
유료 결제하기 -> 사용자 결제 -> 결제 완료 후, 각 지도에서 에어비앤비 위치들 추가 등장(외도민 핀, 에어비앤비 핀 다르게 색상 표시하며 화면의 체크표시에 따라 끄고 킬수있음) : 에어비앤비 숙소위치 핀으로 전부 확인 가능(airroi를 통한 좌표 핀처리 필요) -> 원하는 에어비앤비 숙소 핀을 누르고 '선택 반경'을 원하는 만큼 100m ~ 2km 사이를 고르고 (그럼 그 구간만큼 지도에 색 표시됨) '분석하기' 클릭하면 -> 해당 반경 분석 정밀 리포트가 나옴 (이때 /report 등 추가 다른 주소로 들어가는게 아니라 , 사용자가 보고있던 화면에서 편하게 보고 닫을 수 있게함)

## 리포트 제공 기능
- 선택한 핀 기준 선택 반경만큼 등록된 외도민 개수 (현재 랜딩 페이지에서 제공되는 기능)
- 선택한 핀 주소 기준으로 건축물 대장 봤을때 외도민 등록 가능성 (현재 랜딩 페이지에서 제공되는 기능) + 건축물 대장 pdf 다운로드 기능 제공
- 선택한 핀 기준 선택 반경 기준
	- 동네 평균 객단가
	- 평균 예약률
	- 평균 월 예상 수익
	- 월 수익 구간 분포 (하위, 중위 ,상위 중 어디에 들어가는지)
	- 사용자 선택에 따른 동적기능 제공 : (방 개수, 욕실, 최대 게스트) 사용자 선택하는 수치에 따라 평균 객단가, 평균 월 예상 수익, 월 수익 구간분포 + 이때 거실유무, 엘리베이터 유무 등 추가로 반영할 수 있는 항목들 조사해서 반영 가능하다면 더 반영하기
	* 위에 기능들은 이미 기존 /explore 에서 제공하는 기능인데 이것들을 단순 레포트 형식이 아닌 최대한 시각화 및 차트자료를 통해 최대한 있어보이게 제공하는게 중요함. 시각화 기능 적극활용.
- 수익성 계산기 (현재 랜딩 페이지에서 제공되는 기능의 업그레이드 버전)

[OO동]에 투룸 하나로 외국인 민박을 하려고 해. 아는 건 이게 다야 -- 이때 어느동네인지는 사용자가 선택한 동네
에어비앤비 사이트에서 한 달 꽉 차면 매출 약 OOO만 원, 1박은 OO만 원쯤. [계산 기준 — 이대로만 계산해] -- 사용자가 위 단계에서 선택한거로
1. 시즌은 '성수기'와 '비수기' 두 개로만. (중간 구간 만들지 마)
2. 객실이 하나라 성수기엔 거의 꽉 차 → 성수기 매출은 꽉 찼을 때(약 500만)에 가깝게, 1박 요금은 그대로.
3. 비수기는 성수기의 약 70% 정도로만. (너무 비관적으로 깎지 마)
4. 1년 평균은 성수기 7개월 + 비수기 5개월로.
5. 나가는 돈은 항목별로, 청소비는 직접 하면 0원인 점도.
6. 셋업비는 '가장 싸게(전대·풀옵션)' 기준으로. 겁주는 최대치 말고.
7. 보증금은 돌려받으니 회수·수익 계산에서 빼고 '따로 필요한 목돈'으로만.
8. 복잡한 법·세금 얘기 하지 마. 돈 계산만. [답변은 꼭 이렇게 — 짧고 쉽게]
9. 길게 설명하지 마. 표 하나로, 항목마다 한 줄.
10. 처음 하는 엄마가 한눈에 알아볼 정도로 쉬운 말로.
11. 중요한 숫자(평균 매출·월세 상한·매달 남는 돈·회수기간)는 굵게.
12. 불확실한 건 ⚠️ 짧게만.
13. 맨 끝에 딱 한 줄 결론: "월세 OO 이하면 해볼 만, 넘으면 위험." [알려줘] ① 1년 평균 한 달 매출 ② 매달 나가는 돈 ③ 월세 상한선 ④ 안 돌려받는 돈만으로 회수기간 + 매달 남는 돈 (보증금은 따로)
